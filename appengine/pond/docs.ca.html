Documentació de la Bassa

Bassa

Angles

La brúixola està orientada de manera que l'est (dreta) és 0 graus, 90 és el nord, 180 és l'oest, 270 és el sud. Els angles es repeteixen com és d'esperar: -90 és el sud, 450 és el nord.

Canó

cannon(angle, range)

La funció cannon() dispara una bala de canó cap a l'angle i l'abast especificats. L'angle és independent de la direcció de l'ànec. L'abast pot ser de 0 a 70 metres; els abasts més grans es trunquen a 70.

El canó triga aproximadament un segon a recarregar-se després de disparar. Si es crida cannon() durant aquest temps, no passa res. cannon() retorna true si s'ha disparat una bala de canó, o false si el canó s'està recarregant.

Escaneig

scan(angle)
scan(angle, width)

La funció scan() activa el radar de l'ànec. Aquesta funció retorna la distància fins al contrincant més proper en la direcció especificada. L'angle és independent de la direcció de l'ànec. Els contrincants enfonsats no es detecten. Si no hi ha cap contrincant en aquesta direcció, es retorna Infinity.

El segon paràmetre (opcional) de scan() especifica l'amplada del feix d'escaneig. Pot anar d'1 grau a 20 graus. Els jugadors avançats poden voler començar escanejant amb una amplada de 20 per fer un escaneig ràpid, i després reduir progressivament l'amplada per obtenir més precisió. Si no s'especifica, l'amplada és 5. Aquest paràmetre només està disponible amb JavaScript, no amb blocs.

Nedar

swim(angle)
swim(angle, speed)

La funció swim() fa que l'ànec comenci a moure's. L'ànec continuarà movent-se en la direcció especificada indefinidament.

El segon paràmetre (opcional) de swim() especifica la velocitat. Pot anar de 0 (aturat) a 100 (ràpid). La direcció del moviment només es pot canviar si la velocitat és 50 o menys. Si no s'especifica, la velocitat és 50. Aquest paràmetre només està disponible amb JavaScript, no amb blocs.

Xocar contra les vores de la bassa farà mal al teu ànec. Xocar contra altres ànecs farà mal als dos ànecs. La quantitat de dany és proporcional a la teva velocitat.

Aturar

stop()

La funció stop() fa que l'ànec deixi de moure's. L'ànec trigarà una estona a reduir la velocitat abans d'aturar-se completament. Això és el mateix que cridar swim() amb una velocitat de zero.

Posició

  

getX()
getY()

Les funcions getX() i getY() retornen les posicions horitzontal i vertical de l'ànec. Els valors estan entre 0 i 100, començant per la cantonada inferior esquerra.

Velocitat

speed()

La funció speed() retorna la velocitat actual de l'ànec. Els valors estan entre 0 (aturat) i 100 (ràpid). Aquesta funció es pot utilitzar per detectar col·lisions (que aturen l'ànec instantàniament).

Salut

health()

La funció health() retorna el nivell de salut actual de l'ànec. Els valors estan entre 0 (enfonsat) i 100 (perfecte). Els jugadors avançats poden voler emmagatzemar la salut en una variable i comprovar periòdicament si ha disminuït, cosa que indicaria que l'ànec està sota atac.

No hi ha cap manera de reparar la salut.

Depuració

log()

La funció log() imprimeix el número especificat a la consola del navegador. Això és molt útil per depurar el codi.

Lògica

Si

if (condition) {
  statements
}


if (condition) {
  statements
} else if (condition) {
  statements
}


if (condition) {
  statements
} else {
  statements
}

Si la condició és certa, s'executen les instruccions contingudes. El if pot anar seguit de qualsevol nombre de condicions else if addicionals, i al final d'una condició else opcional que s'executa si cap de les condicions anteriors era certa.

Igualtat

==    !=    <    <=    >    >=

Aquestes expressions comparen dos números i retornen true o false. Els sis operadors d'igualtat disponibles són:

Operador Exemple Retorna
Igual a 5 == 10 false
Diferent de 5 != 10 true
Menor que 5 < 10 true
Menor o igual que 5 <= 10 true
Major que 5 > 10 false
Major o igual que 5 >= 10 false

L'ús de != pot ser perillós si els números que es comparen són fraccions. Considereu aquest codi dissenyat per nedar fins a 50 i després aturar-se:

while (getY() != 50) {
  swim(90, 50);
}
stop();

Aquest codi probablement fallarà perquè getY() pot valer 49.4 en una execució i 50.6 en la següent. Com que el valor no s'ha vist exactament a 50, el bucle continua per sempre. A continuació hi ha un codi millor:

while (getY() < 50) {
  swim(90, 50);
}
stop();

I / O

&&    ||

«I» es representa amb l'operador &&. Retorna true només si totes dues entrades són true. Per exemple, aquest codi només dispararà el canó si l'abast és alhora superior a 5 i inferior a 70:

if (range > 5 && range < 70) {
  cannon(angle, range);
}

«O» es representa amb l'operador ||. Retorna true si alguna de les entrades és true. Per exemple, aquest codi aturarà l'ànec si està a prop de qualsevol paret:

if (getX() < 10 || getX() > 90 ||
    getY() < 10 || getY() > 90) {
  stop();
}

Booleans

true    false

El valor true s'utilitza principalment amb el bucle while per crear un bucle que s'executa per sempre. El valor false també està disponible.

Bucles

Mentre

while (condition) {
  statements
}

Els bucles repeteixen l'execució de les instruccions contingudes mentre la condició sigui certa. Així, el següent codi dispararà el canó cap a l'oest per sempre:

while (true) {
  cannon(180, 50);
}

Mentre que el següent dispararà el canó cap a l'oest mentre hi hagi un contrincant a l'abast:

while (scan(180, 5) <= 70) {
  cannon(180, scan(180, 5));
}

Matemàtiques

Número

123

Els números s'utilitzen per a moltes coses, com ara abasts, angles i comptadors. Els números poden ser negatius (p. ex. -360), fraccionaris (p. ex. 3.14159), o molt grans (p. ex. 9007199254740992). Fins i tot hi ha un número especial anomenat Infinity.

No utilitzeu separadors de milers (p. ex. 9.000).

Aritmètica

+    -    *    /

Aquests operadors prenen dos números i en retornen un de sol. Els quatre operadors aritmètics disponibles són:

Operador Exemple Retorna
Suma 3 + 4 7
Resta 3 - 4 -1
Multiplicació 3 * 4 12
Divisió 3 / 4 0.75

Trigonometria

Math.operation(number)

Aquestes funcions prenen un número i en retornen un altre. Les vuit funcions disponibles són:

Funció Exemple Retorna
Arrel quadrada Math.sqrt(25) 5
Valor absolut Math.abs(-25) 25
Sinus Math.sin_deg(30) 0.5
Cosinus Math.cos_deg(30) 0.86
Tangent Math.tan_deg(30) 0.577
Arcsinus Math.asin_deg(0.5) 30
Arccosinus Math.acos_deg(0.866) 30.003
Arctangent Math.atan_deg(0.577) 29.985

Tingueu en compte que aquestes funcions trigonomètriques són pròpies del joc de la Bassa i totes utilitzen graus. Les funcions estàndard de JavaScript utilitzen radians.

Aleatori

Math.random()

Aquesta funció retorna una fracció aleatòria d'entre 0.0 i 1.0. Per obtenir un número aleatori en un interval més gran, només cal multiplicar-lo pel valor màxim. Aquí teniu un exemple per obtenir un angle aleatori:

var angle = Math.random() * 360;

Variables

Assignació

var name = value;

Assigna un valor (normalment un número) a la variable amb nom. El nom de la variable hauria de tenir sentit, com ara range o angle.

Tingueu en compte que els noms de variable distingeixen entre majúscules i minúscules, per tant angle i Angle són dues variables completament diferents. Els noms de variable només poden utilitzar les lletres angleses a-z i números. Els noms de variable no poden començar amb un número.

La paraula clau var es pot ometre a totes les assignacions excepte la primera, però no hi ha cap problema a utilitzar-la sempre.

Increment

name += number;

Això és una drecera per sumar un número a una variable existent. No hi ha cap diferència entre les dues línies següents:

angle += 10;
var angle = angle + 10;

No utilitzeu += en una variable que encara no s'hagi definit. Si teniu dubtes, assigneu 0 a la variable a l'inici del programa.

Recuperació

name

Recupera el valor (normalment un número) que s'havia assignat prèviament a la variable amb nom.
